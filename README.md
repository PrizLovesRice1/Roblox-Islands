# Priz's Islands Hub

Advanced automation and management script for Roblox Islands game.

## Features

- **Home Tab**: Scanner & Stats, Openables Opener, Chest Manager
- **Vendings Manager**: Complete vending machine management system
- **Block Printer**: Block placement tools
- **Automation**: Auto-restock, auto-deposit, auto-stocker
- **Farming**: Crop farming, auto-walk, crop planting, auto-eat
- **Settings**: Performance optimization, player controls, hotkeys
- **Presets**: Save and load vending groups and favorites

## Installation

1. Clone this repository
2. Load the main.lua file in your Roblox executor
3. The script will automatically load all modules

## Usage

### Hotkeys
- **F1**: Withdraw All
- **F2**: Deposit All
- **F3**: Select Random Vending
- **F4**: Scan Vendings
- **F5**: Empty All

### ALT+Click
- **ALT + Click** vendings to select them for bulk operations
